# Проверка BARE LISS.

Проверен production static export Next.js в установленном Chrome на Windows. Отчёты: `qa/report.json`, `qa/lighthouse-mobile.json`.

Версия для GitHub Pages отдельно собрана с `NEXT_PUBLIC_BASE_PATH=/bareliss` и проверена на `http://127.0.0.1:3001/bareliss/`. Сохранены все 28 проверок, включая изображения, динамическую загрузку игры и маршруты под префиксом репозитория.

- 28 браузерных проверок — пройдены.
- Console/page errors — 0.
- PLUCK — mouse drag первого волоса, keyboard для оставшихся 24, переход после завершения.
- LASER — область обработана за 12 импульсов; один импульс обрабатывает группу волосков.
- Touch — реальная последовательность touchStart/touchMove/touchEnd через Chrome DevTools Protocol удаляет волос; кнопка перехода и импульс работают.
- Skip и restart — проверены в flow.
- Booking — все 8 шагов, изменение зоны на комплекс, дата/время, имя, проверка телефона, итоговое демо-подтверждение.
- Zone selector, price filters, FAQ, mobile menu — пройдены.
- Переполнение — отсутствует на 320, 375, 390, 430, 768, 1024, 1280, 1920 px.
- Reduced motion — плавный скролл отключён, тяжёлые эффекты отключены CSS.
- Все шесть маршрутов отвечают 200.
- Production build и встроенная проверка TypeScript — проходят.

Мобильный Lighthouse на локальном production-экспорте: Performance **91**, Accessibility **100**, Best Practices **100**, SEO **100**. Это один лабораторный запуск, а не гарантия результата на всех устройствах и сетях.

Снимки: `qa/desktop.png`, `qa/mobile.png`, `qa/experience.png`.

Не проверялось на физическом телефоне. Вибрация и звук зависят от поддержки и настроек устройства. Реальная CRM, реальная доступность мастеров и реальные контакты не предоставлены; запись явно демонстрационная.
